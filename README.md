# 92 AMXS Tracker

> Logbook and training tracker for the 92nd Aircraft Maintenance Squadron.

Tracking who's current on what in a maintenance squadron is a paperwork nightmare. Between upgrade training, recurring certifications, and task qualification updates, it's easy to lose track. This is a simple tool to keep it straight.

---

## What It Tracks

- **Training status** — Who's in upgrade training, what phase, what's remaining
- **Certifications** — Red X, yellow, green status with expiration dates
- **Task qualifications** — 5-level, 7-level progression
- **Logbook entries** — Sortable, filterable by section and date

---

## Tech Stack

React 19, Vite 8, TailwindCSS 4.

```bash
npm install
npm run dev
```
